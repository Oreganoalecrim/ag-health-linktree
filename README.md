# AG Health Linktree
Microsite estático, mobile-first, sem backend e sem coleta de dados. Edite os destinos oficiais em `config.js`; cartões e redes sem URL são ocultados. Substitua `assets/profile-placeholder.svg` pela fotografia aprovada. Importe este repositório no Lovable via GitHub e publique em `*.lovable.app`. Não inclua tokens ou segredos.

Teste local: `python3 -m http.server 4173` e abra `http://localhost:4173`.
